# VideoCreator Roadmap

## Phase 1: Core Foundation & Desktop MVP (Completed)
- [x] Clean Architecture solution structure (.NET 8 + Avalonia UI 11).
- [x] Non-destructive multi-track timeline with undo/redo command pattern.
- [x] Ken Burns photo motion engine (Zoom, Pan, Diagonal, Cinematic).
- [x] Smart crop with blurred background generation.
- [x] Real-time SkiaSharp preview compositor.
- [x] Frame-accurate 1080p / 4K MP4 export with audio mixing and fades.
- [x] Data-driven template system (Cinematic, Memories, Birthday, Travel, Instagram Reel, Festival).
- [x] 4-step Quick Create wizard and full studio multi-track editor.
- [x] Audio analysis, BPM detection, and waveform rendering.
- [x] Autosave snapshots and crash recovery.
- [x] Automated test suite & end-to-end acceptance test.

## Phase 2: Advanced Editing Features
- [ ] Multi-layer video PIP (Picture-in-Picture) blending.
- [ ] Curve-based custom keyframe easing editor in UI.
- [ ] LUT color grading support (.cube format).
- [ ] Audio equalizer and vocal noise reduction.

## Phase 3: Cloud & Web Services
- [ ] ASP.NET Core cloud rendering API.
- [ ] Blazor WebAssembly lightweight browser player.

## Phase 4: Mobile Applications
- [ ] Touch-optimized UI for iOS and Android.
- [ ] Mobile camera roll direct import.
